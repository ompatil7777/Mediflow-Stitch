Unified RBAC Security Boundary Matrix

कठोर सुरक्षा धोरण

Principle of Least Privilege enforced at hardware and cryptographic API layers.

person 1. Citizen / Patient (नागरिक / रुग्ण)
Tier 0
Permitted Scopes: Self-profile management, appointment booking, own care history, read-only PHC medicine availability index.
Hard Security Boundaries: Zero access to other patient identities, inventory logs, clinical triage charts, or stock adjust commands.
health_and_safety 2. Health Worker / ANM / ASHA (आरोग्य सेविका)
Field Tier
Permitted Scopes: Assigned village roster check, clinical triage entry (vitals/symptoms), doctor care coordination, read-only PHC medicine query.
Hard Security Boundaries: Strictly prohibited from dispensing statutory drugs, altering physical stock, approving requisitions, or administrative user edits.
medication 3. PHC Pharmacist (औषध निर्माण अधिकारी)
Facility Tier
Permitted Scopes: Dispensary inventory custody, statutory Rule 65 dispensing, replenishment requisitioning (#REQ), delivery QR scanning and acceptance.
Hard Security Boundaries: No cross-PHC modifications, no authority to self-approve replenishment indents, no access to system server configs.
account_balance 4. District Authority / DHO (जिल्हा आरोग्य अधिकारी)
District Tier
Permitted Scopes: District-wide PHC operational telemetry, consumption analysis, requisition approval/redirection, depot allocation sign-offs.
Hard Security Boundaries: Cannot dispense direct medication to citizens, cannot manually alter physical depot bin counts without warehouse custodian counter-sign.
warehouse 5. Supply Depot Operator (मध्यवर्ती कोठार व्यवस्थापक)
Logistics Tier
Permitted Scopes: Allocation order picking, FEFO batch serial assignment, cold-chain sensor association, reefer fleet outward gate-pass.
Hard Security Boundaries: No access to patient identifiable health records (EHR/PHR), cannot initiate requisitions, cannot modify approved quotas.
terminal 6. System Administrator (प्रणाली नियंत्रक)
Root Admin
Permitted Scopes: Identity lifecycle management, PKI certificate issuance, RBAC scoping, facility node topology mapping, audit ledger immutability monitoring.
Hard Security Boundaries: Strictly barred from entering clinical diagnosis notes, modifying live medicine inventory quantities, or approving drug dispatches.
