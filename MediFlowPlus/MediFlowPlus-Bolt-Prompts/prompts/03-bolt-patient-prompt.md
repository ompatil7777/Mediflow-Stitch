# MediFlow+ — Phase 2: Patient

Implement the Patient/Citizen module using the Stitch designs and existing architecture.

Implement:
- Dashboard
- Profile
- Find PHC
- PHC Search Results
- PHC Details
- Appointment Booking
- Slot Selection
- Confirmation
- My Appointments
- Appointment Details
- Medicine Availability
- Medicine Details
- Request/Status where specified
- Notifications
- Loading/Empty/Error/Success states

Clearly distinguish Home/Registered PHC from Appointment PHC. A patient may book at another PHC in the same district without changing home PHC.

Do not implement diagnosis, prescriptions, treatment recommendations or autonomous medical decisions.

Test mobile and all three languages. Run build/typecheck/lint.
